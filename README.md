
# 🏡 Sistema de Gestión para Conjuntos Residenciales

Este es un **proyecto estudiantil** diseñado para simplificar la administración y gestión de procesos en complejos residenciales. ¡Una herramienta útil y práctica para mantener todo en orden!

***

### **🎯 ¿Cuál es su objetivo?**

El propósito principal de este sistema es ofrecer una solución web para **gestionar las reservas de áreas comunes, el registro de residentes y el control de vehículos** dentro de un conjunto residencial.

***

### **✨ Características Principales**

* **Gestión de Reservas:** Permite a los residentes reservar espacios comunes como salones sociales o áreas deportivas.
* **Control de Residentes y Mascotas:** Lleva un registro organizado de todos los habitantes del conjunto y sus mascotas.
* **Administración de Parqueaderos:** Facilita la asignación y el control de los espacios de estacionamiento.

***

### **💻 Stack Tecnológico**

El proyecto está construido con un conjunto de tecnologías web robustas y ampliamente utilizadas:

* **Frontend:** HTML, CSS y JavaScript.
* **Backend:** **PHP** como lenguaje principal de servidor.
* **Base de Datos:** **MySQL** para el almacenamiento de datos.

***

Este proyecto es una excelente base para aprender sobre desarrollo web con PHP y puede ser adaptado o expandido para incluir nuevas funcionalidades.
